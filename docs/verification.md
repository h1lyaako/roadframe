Прочерк означает пустой список отметок. На двух московских записях движения в кадре оказалось недостаточно для прежнего порога. Теперь алгоритм также ищет короткий всплеск в нескольких полосах звука и проверяет, изменилось ли в этот момент движение на одном участке дороги. На ночной записи есть второй громкий звук на 26,24 с. Он не дал дополнительной отметки. Звёздочкой обозначены отметки по звуку и движению в режиме Qwen. Их нельзя считать независимым подтверждением моделью.

## Сколько приходится смотреть

В Edge загрузили папку целиком и перешли по каждой отметке. В семи файлах содержится 3 мин 26 с видео. От выбора папки до готовности всех результатов прошло 88 с на этом компьютере, включая подготовку видео для браузера. Приложение предложило пять отрывков по 7 с, всего 35 с просмотра. Прежняя версия предлагала три отрывка и теряла два различимых происшествия. Седьмой файл снят после аварии из первого. Второй файл исключён из оценки точности из-за неопределённости. Эта папка использовалась для настройки, поэтому результат не измеряет точность на других дорогах. Время ручного поиска отдельно не замеряли.

## Две записи за пределами подборки

Эти публикации выбрали после исправления OpenCV. Его настройки после прогона на них сохранили.

- **Ялуторовск, легковой автомобиль и мотоцикл.** На кадрах в 2,00–2,25 с видно столкновение. OpenCV его пропустил. Codex открыл эпизод на 1,88 с. Qwen при первой проверке ошибочно отметил 6,55 с, когда машина уже остановилась. Этот случай использовали для исправления проверки Qwen. При повторном запуске ложная отметка исчезла, сам удар Qwen пропустил. [Видео](https://t.me/russiancrash/7409)
- **Барнаул, машина справа от регистратора.** Видно сближение около 10–11 с. Место предполагаемого контакта у края капота, поэтому точное время удара по кадрам подтвердить не удалось. OpenCV вернул пустой список. Codex предложил 10,88 с с подписью «Видны последствия происшествия». В число подтверждённых попаданий этот результат не вошёл. [Видео](https://t.me/russiancrash/7405)

## Как повторить проверку

Из корня репозитория с установленными Python, FFmpeg, FFprobe и зависимостями проекта выполните:

```powershell
python -m unittest discover -s tests -v
```

Автотесты обрабатывают реальные видео и отдельно проверяют изменённое начало ролика, сдвиг аудиодорожки, громкий звук при неподвижной картинке, нечётные размеры кадра и два ракурса в одном контейнере. Проверяются также экспорт, границы отрывка и восстановление очереди после повреждённого файла.

Для проверки через браузер запустите сервер, установите Python-пакет `playwright` и выполните следующую команду на компьютере с Microsoft Edge:

```powershell
python tests/check_browser.py
```

Браузер открывает вложенную папку, пропускает повреждённый файл, проверяет порядок записей и переходит по отметке. Затем он скачивает трёхсекундный MP4. Тест сверяет длительность и кадр в момент аварии с исходной записью.
