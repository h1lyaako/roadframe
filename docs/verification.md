Два новых попадания OpenCV относятся к стационарным камерам. В этих случаях Qwen подтвердил эпизод по изображениям, а секунду приложение взяло из расчёта траекторий. На регистраторе в Петербурге отметка OpenCV появляется примерно за полсекунды до видимого контакта. Подборка использовалась при разработке.

## Две записи за пределами подборки

Эти публикации выбрали после исправления OpenCV. Его настройки после прогона на них сохранили.

- **Ялуторовск, легковой автомобиль и мотоцикл.** На кадрах в 2,00–2,25 с видно столкновение. OpenCV его пропустил. Codex открыл эпизод на 1,88 с. Qwen при первой проверке ошибочно отметил 6,55 с, когда машина уже остановилась. Этот случай использовали для исправления проверки Qwen. При повторном запуске ложная отметка исчезла, сам удар Qwen пропустил. [Видео](https://t.me/russiancrash/7409)
- **Барнаул, машина справа от регистратора.** Видно сближение около 10–11 с. Место предполагаемого контакта у края капота, поэтому точное время удара по кадрам подтвердить не удалось. OpenCV вернул пустой список. Codex предложил 10,88 с с подписью «Видны последствия происшествия». В число подтверждённых попаданий этот результат не вошёл. [Видео](https://t.me/russiancrash/7405)

## Как повторить проверку

Из корня репозитория с установленными Python, FFmpeg, FFprobe и зависимостями проекта выполните:

```powershell
python -m unittest discover -s tests -v
```

Автотесты обрабатывают реальные видео и отдельно создают файлы для проверки нечётных размеров кадра, длинной звуковой дорожки и двух ракурсов в одном контейнере. Проверяются также экспорт, границы отрывка и восстановление очереди после повреждённого файла.

Для проверки через браузер запустите сервер, установите Python-пакет `playwright` и выполните следующую команду на компьютере с Microsoft Edge:

```powershell
python tests/check_browser.py
```

Браузер открывает вложенную папку, пропускает повреждённый файл, проверяет порядок записей и переходит по отметке. Затем он скачивает трёхсекундный MP4. Тест сверяет длительность и кадр в момент аварии с исходной записью.
