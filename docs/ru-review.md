# Разбор ДТП по ПДД РФ

На Windows x64 установите обычные зависимости проекта, затем один раз запустите из его папки:

```powershell
.\install-vision.ps1
```

Установщик скачивает около 3 ГБ в `%LOCALAPPDATA%\Roadframe` и проверяет SHA-256. Нужна видеокарта с актуальным драйвером Vulkan для быстрого разбора. При готовой установке запустите веб-приложение обычной командой из README. Выберите «Разобрать записи из России по ПДД РФ» перед открытием файла или папки. Место съёмки указывает пользователь. Кнопка «Пример из России» обрабатывает две [российские записи](../test-videos-ru/README.md). Кнопка «Скачать отчёт по архиву · PDF» появляется в разделе разбора, когда готовы результаты. Пропущенные при загрузке файлы перечисляются в отчёте.

При первом разборе сервер загружает [Qwen3-VL-4B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF) в память. [llama.cpp](https://github.com/ggml-org/llama.cpp) принимает кадры только через локальный адрес. Доступ к интернету нужен для установки. За распознавание по API платить не требуется. На другой ОС можно запустить тот же llama-server вручную с моделью и визуальным проектором, именем `-a roadframe-local` и портом 18068 на 127.0.0.1.

## Что анализирует модель

Обзор охватывает весь файл с шагом в секунду. Соседние окна перекрываются. Для вида из салона OpenCV дополнительно ищет резкое изменение движения десять раз в секунду. Для уличной камеры приложение пять раз в секунду сравнивает движущиеся объекты с фоном и ищет сближение. Проверка устойчивого изменения фона после сближения помогает отсеять обычный проезд. Вокруг подозрительного момента модель смотрит последовательность кадров с шагом в полсекунды. При наличии координат она видит увеличенный участок и весь кадр для проверки обстановки. Такой поиск может пропустить удар в конце файла или столкновение, после которого водители сразу разъехались. Время в PDF приблизительное, указано от начала соответствующего файла. На стыке файлов фрагменты автоматически не склеиваются. В PDF попадают кадры из исходника с подписями времени и, если найдена область сближения, её увеличенная копия. Описания составляются по коротким ответам модели. При разногласии между общим планом и увеличением детали могут быть опущены. Звук в распознавании не используется.

Для обычных регистрационных знаков легковых машин выводится полная строка с кодом региона, только если две независимые расшифровки разных кадров совпали. Отдельный запрос читает увеличенный участок таблички без подсказки. Проверка формата и совпадения уменьшает риск ошибки. Модель может одинаково ошибиться дважды. Номер относится к кадру, по нему приложение не определяет личность водителя.

## Как применяются правила

Веса модели готовые. При каждом разборе ей передаётся [справочник](../pdd.py) с условиями применения 21 пункта. Он покрывает сигналы светофора, выезд со двора, смену полосы, движение задним ходом, дистанцию, выбор скорости, приоритет на перекрёстке и переходы. Приоритет сверяется по знакам и сигналам для конкретного направления. Удар сзади сам по себе не показывает, как машины оказались в одной полосе. Для вывода о скорости требуется отдельное измерение. Справочник составлен по [постановлению № 1090](https://www.consultant.ru/document/cons_doc_LAW_2709/), редакция от 28.08.2026. Для исторической записи пользователь отдельно сверяет редакцию на дату происшествия. Приложение автоматически её не подбирает.

Отчёт содержит версию непосредственно наблюдаемого события и описывает, действия какого участника требуют проверки. Возможную связь участника с конкретным пунктом проверяет дополнительный запрос к той же модели. Обзор может пропустить короткий или закрытый кузовом удар. Значение для административного дела определяется в совокупности с другими доказательствами. См. [ст. 1.5](https://www.consultant.ru/document/cons_doc_LAW_34661/c4e643d138637f4eafb763d628fc44ef99c71a15/), [ст. 26.2](https://www.consultant.ru/document/cons_doc_LAW_34661/747b7ded7acccf4fbd94a98fe212713ae1845601/) и [ст. 26.11 КоАП РФ](https://www.consultant.ru/document/cons_doc_LAW_34661/46a9b456fc041022585b2d13cda9d666fc11ffd4/). Ответственность за вред при взаимодействии транспортных средств зависит в том числе от того, кому причинён вред. [Ст. 1079 ГК РФ](https://www.consultant.ru/document/cons_doc_LAW_9027/27fb9de9d0fa6adb1f00e22c245b99251d5bd23f/).

## Проверка на российских записях

Эксперимент выполнен 22 ноября 2026 года на ноутбуке с GeForce RTX 4060 Laptop. Каждый файл проходил обычную загрузку в веб-приложение. Время и описание события из публикации модель не получает. Контрольные интервалы оценены по кадрам вручную. В таблице указано время работы уже загруженной модели и поиска на OpenCV. Загрузка файла и подготовка видео для плеера в этот столбец не входят.

Отметки приложения совпали с районом удара на трёх из пяти записей с видимым происшествием. Среди трёх таких записей с регистратора найдена одна. Часть материала использовалась для настройки. Дневную запись из Москвы проверили после завершения изменений, её алгоритм пропустил. Отрезок без нового удара взят из того же видео, что и первый пример. Озёрск в подсчёт попаданий не входит.

Первый обзор только по общим кадрам пропустил и Трёхгорный, и Челябинск. После добавления увеличения и проверки изменений на дороге появились обе нужные отметки. В одном промежуточном прогоне по Челябинску были три лишние отметки. В итоговом прогоне осталась одна, рядом с ударом. Папка с двумя встроенными записями общей длиной 111 секунд прошла весь путь от нажатия кнопки до готового результата в браузере за 79 секунд. Отдельные сложные записи обрабатывались дольше их длительности.

На этих записях не удалось подтвердить госномер по двум кадрам или обосновать нарушение конкретного участника. Качество этих двух функций на положительных примерах пока не установлено. Подборка также не даёт оценки точности для произвольной папки.
