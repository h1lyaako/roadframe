# Поиск момента ДТП с Qwen

На Windows x64 установите зависимости из [README](../README.md) и запустите из папки проекта:

```powershell
.\install-vision.ps1
```

Установщик скачает около 3 ГБ в `%LOCALAPPDATA%\Roadframe` и проверит SHA-256. Для быстрого поиска нужна видеокарта с поддержкой Vulkan. Запустите `python server.py`, выберите «Qwen · на компьютере» и откройте файл или папку. Для встроенной демонстрации нажмите «Пример ДТП».

[Qwen3-VL-4B](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF) получает кадры через локальный llama-server. Для обзора берётся кадр в секунду. При съёмке с регистратора OpenCV дополнительно ищет резкие изменения движения, а для камеры над дорогой отслеживает сближения. Найденные эпизоды Qwen проверяет по кадрам с шагом в полсекунды. Нажатие на отметку перематывает видео к предполагаемому удару. Короткий или закрытый удар модель может пропустить.

Для записей, которые модель распознала как съёмку с регистратора, приложение сохраняет и отдельные отметки «Возможное ДТП по звуку и движению». Они появляются, когда резкий звук совпал с местным изменением движения, а модель не нашла рядом свой момент. Звук обрабатывается на компьютере.

На другой ОС можно запустить llama-server с той же моделью и визуальным проектором на `127.0.0.1:18068` с параметром `-a roadframe-local`. [Российские записи для проверки](../test-videos-ru/README.md)
