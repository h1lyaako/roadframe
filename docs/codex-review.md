# Поиск момента ДТП с Codex

1. Установите зависимости приложения из [README](../README.md) и [Codex CLI](https://developers.openai.com/codex/cli/).
2. Выполните `codex login` и выберите вход через ChatGPT. Проверить вход можно командой `codex login status`.
3. Запустите `python server.py` и откройте [приложение в режиме Codex](http://127.0.0.1:18065/?mode=codex). Выберите файл, папку с записями или встроенный пример.
4. Нажмите отметку в списке или на шкале. Плеер откроет исходный файл на указанной секунде. Можно сохранить в MP4 отрывок до и после отметки.

Для обзора Codex получает один кадр в секунду. Вблизи предполагаемого удара шаг уменьшается до четверти секунды. Если общий план не дал отметок, OpenCV ищет сближения и устойчивые изменения на дороге. Подходящие участки Codex проверяет крупнее. Когда точка контакта скрыта, подпись «Видны последствия происшествия» указывает на первый замеченный признак, например разлёт обломков. Время самого удара может быть раньше.

В OpenAI передаются выбранные кадры через аккаунт пользователя. Расходуются лимиты Codex. Место на шкале отсчитывается от начала файла. [Записи для самостоятельной проверки](../test-videos-ru/README.md)
