# Разбор ДТП через личный Codex

[Посмотреть пример PDF по Санкт-Петербургу](codex-example.pdf) · [Открыть исходную запись](../test-videos-ru/04-saint-petersburg.mp4) · [Все семь тестовых видео](../test-videos-ru/README.md)

## Запуск

1. Установите зависимости из [README](../README.md), FFmpeg и [Codex CLI](https://developers.openai.com/codex/cli/).
2. Один раз выполните `codex login` и выберите вход через ChatGPT. Команда `codex login status` должна подтвердить этот способ входа. Приложению нужен доступный в PATH исполняемый файл Codex CLI с поддержкой изображений и структурированного ответа.
3. Запустите `python server.py`, откройте [приложение в режиме Codex](http://127.0.0.1:18065/?mode=codex) и выберите запись или папку. Для двух встроенных записей нажмите «Пример из России». После разбора скачайте PDF.

Кадры и написанные приложением запросы передаются в OpenAI через действующий вход в Codex. Расходуются лимиты аккаунта ChatGPT для Codex. Приложение не копирует токен и не требует отдельного API-ключа. Имя файла, звук, ручная разметка и текст публикации в запрос не попадают. Два других режима, «Поиск движения» и «Qwen · ПДД РФ», обрабатывают видео локально.

## Что получает пользователь

Для петербургской записи в отчёте видны три этапа. Тёмный седан появляется слева, пересекает линии разметки перед регистратором и оказывается рядом с кабиной красного самосвала. Codex выделил интервал 4,00–4,25 с и предложил первым проверить манёвр седана по п. 8.1 ПДД РФ. Для разбора действий второго водителя важно видеть, сохранял ли самосвал полосу до сближения. Это предварительная версия по одному ракурсу.

Программа разбирает каждый файл по всей длине отдельными окнами. Для обзора берётся кадр в секунду. Вокруг найденного места Codex получает четыре кадра в секунду с таймкодами. Если обзор не дал отметок, программа проверяет сближения на общем плане средствами OpenCV и отправляет подходящие участки крупнее. Обстановка, движения участников и ограничения ракурса описаны отдельно. При скрытом контакте отметка относится к видимому последствию удара. Пункт ПДД выбирается из [справочника](../pdd.py). Номер появляется только при совпадении двух отдельных чтений фрагментов разных кадров.

Результаты обрабатывает модель, которую выбирает CLI. Её фактическое имя сохраняется в PDF. Большой архив потребует больше времени и лимита, чем короткий одиночный клип.
## Результат проверки

На тех же файлах сравнили интервалы Codex с предыдущим прогоном Qwen и ручным просмотром. Время отсчитывается от начала каждого файла. Имена и контрольные таймкоды не передавались моделям.

| Запись | Прежняя отметка Qwen | Что отметил Codex | Время разбора Codex |
| --- | --- | --- | --- |
| Санкт-Петербург | 4,2 с, версия причины отсутствовала | Контакт, 4,00–4,25 с. Описал пересечение разметки и положение машин у кабины самосвала | 47 с |
| Трёхгорный | 15,9 с | Контакт, 15,50–15,75 с. Описал подход двух светлых машин с разных направлений | 108 с |
| Челябинск | 9,3 с | Последствия, 10,50–10,75 с. Первый прогон пропустил событие. При повторе отметка заметно позже ручного интервала 8,75–9,25 с | 57 с |
| Москва, ночная запись | Пропуск | Последствия, 9,75–10,00 с. Вручную событие отмечено около 9 с | 57 с |
| Москва, дневная запись | Пропуск | Последствия у ограждения, 7,50–7,75 с. Сам первый контакт закрыт | 46 с |
| Трёхгорный, проезд после ДТП | Без отметок | Без отметок о новом ДТП | 72 с |
| Озёрск | Без отметок | Без отметок. Прямой контакт при ручном просмотре уверенно не установлен | 27 с |

Модель этого прогона — gpt-6.2-sol в личном Codex. На пяти записях с известным ДТП получились две отметки контакта и три отметки последствий. Ни одного госномера по двум кадрам подтвердить не удалось. Контрольный отрывок взят из того же видео, что и Трёхгорный. На небольшой подборке проверяется воспроизводимость демонстрации; оценка качества на новых записях требует отдельного набора.

Для Челябинска, Озёрска и контрольного отрывка приведён повторный прогон после добавления поиска небольших событий на дальнем плане. Во время повторного прогона в Челябинске сам обзор Codex выделил кандидата. Результаты модели могут различаться между запусками. Сравнение относится к поиску событий и содержанию описания. Юридические решения по этим ДТП для проверки виновности не использовались.
