# Дорожный кадр

Локальное веб-приложение для поиска возможных столкновений в папке с видеорегистратора. Оно показывает отметки из разных файлов в общем списке и сохраняет выбранный отрывок в MP4. Браузер работает с сервером на этом же компьютере.

[Описание проекта](docs/project-description.md) · [Презентация для защиты (.pptx)](docs/roadframe-defense.pptx)

## Зачем нужен проект

Когда время происшествия неизвестно, водителю приходится открывать записи с карты памяти и просматривать их одну за другой. Цель проекта — сократить ручной просмотр архива. Пользователь открывает папку, проверяет предложенные моменты на видео и сохраняет нужный фрагмент.

### Что уже сделано

- Импорт папок и вложенных каталогов. Ошибка в одном файле не останавливает обработку остальных.
- Общий список отметок с переходом к нужному файлу и секунде.
- Просмотр исходной записи, настройка начала и конца отрывка, экспорт MP4 из текущего файла.
- Поиск на OpenCV с проверкой движения в соседних кадрах и отдельной проверкой перекрытия обзора.

### Что осталось

Собрать отдельную подборку без повторов, вручную разметить моменты столкновений и проверить обе версии на одних файлах. Измерить долю найденных столкновений, ложные отметки на час записи, ошибку времени отметки и время поиска вручную и с программой. Планируемый итог — приложение для разбора архива и отчёт с воспроизводимыми замерами.

## Запуск

Нужны Python 3.10+ и FFmpeg с FFprobe в PATH. Из этой папки:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

Откройте http://127.0.0.1:18065. Если порт занят, запустите `server.py --port 18066` и откройте этот порт. Нажмите «Открыть папку» и выберите каталог на карте памяти или на компьютере. Через «Выбрать видео» можно загрузить один или несколько файлов. Кнопка «Пример поездки» запускает анализ трёх фрагментов обычной поездки.

Приложение принимает MP4, MOV, WebM, MKV и AVI, включая видео во вложенных папках. Порядок задаётся относительными именами файлов с естественной сортировкой чисел. Неподдерживаемые форматы игнорируются, а ошибки обработки отображаются в списке пропущенных файлов. Предел на один архив составляет 100 файлов и 20 ГиБ, на один файл — 1 ГиБ и 60 минут. Загруженные файлы и отрывки хранятся во временной папке процесса. При штатной остановке сервера эта папка удаляется.

Строка в списке моментов открывает исходный файл на нужной секунде. Время слева в строке показывает позицию в архиве, рассчитанную как сумма длительностей предыдущих файлов и позиция внутри текущего. Оно может отличаться от времени на часах регистратора. По окончании воспроизведения открывается следующий доступный файл. Выбор и экспорт отрывка работают в пределах текущего файла.

## Как работает анализ

- FFmpeg читает 10 кадров в секунду для анализа и сохраняет отрывки из исходного файла.
- OpenCV измеряет оптический поток, компенсирует общее движение камеры и ищет локальные изменения скорости и направления движения. Оценка должна держаться несколько кадров. Для почти неподвижной камеры действует отдельный порог.
- Соседние всплески объединяются. Система ставит отметку у начала первого подтверждённого всплеска, чтобы не отправлять зрителя сразу к последствиям.
- Отдельная проверка ищет резкое и устойчивое перекрытие обзора в нижней части кадра, например поднявшимся капотом. Пока обзор перекрыт, система подавляет повторные отметки по движению.

Это эвристический метод компьютерного зрения. Отметка указывает на возможное столкновение и требует просмотра. Заносы и последствия ДТП не входят в цель поиска. Для сравнения сохранена предыдущая функция `analyze_baseline` в `analysis.py`.
